# Features

This page describes the core features of the TAO product documentation site.

## Static Site Generation

Built with [VitePress](https://vitepress.dev), the documentation is rendered as a fast, static site suitable for GitHub Pages or any static host.

## Search-Ready Structure

Pages are organized into a clear hierarchy with navigation and sidebar menus, making information easy to find.

## Customizable Theme

VitePress's default theme can be extended with custom CSS, components, and configuration to match the TAO brand.

## Markdown Enhancements

Write documentation in Markdown with support for:

- Code blocks with syntax highlighting
- Tables
- Alerts and callouts
- Embedded Vue components

## CI/CD Friendly

The project is designed to be built and deployed automatically with GitHub Actions or any CI pipeline.
