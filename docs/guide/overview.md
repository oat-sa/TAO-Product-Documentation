# Overview

TAO is an agentic project focused on building autonomous, reliable, and observable systems. This documentation covers the product's concepts, architecture, and usage.

## What is TAO?

TAO provides the foundational documentation and guides for designing and operating agentic workflows. Whether you are building assistants, automation pipelines, or multi-agent systems, TAO offers a structured reference.

## Documentation Structure

- **Getting Started**: Setup and run the documentation site locally.
- **Guide**: In-depth explanations of features, architecture, and best practices.

## Goals

- Clarify the product's purpose and capabilities.
- Provide reproducible setup instructions.
- Maintain a single source of truth for product knowledge.
