# TAO Product Documentation

Product documentation for the TAO agentic project.

## About

This repository contains the source for the TAO documentation site, built with [VitePress](https://vitepress.dev).

## Quick Start

```bash
git clone https://github.com/fdrs10/TAO-Product-Documentation.git
cd TAO-Product-Documentation
npm install
npm run docs:dev
```

Visit `http://localhost:5173` to view the site.

## Scripts

- `npm run docs:dev` — Start the development server.
- `npm run docs:build` — Build the static site.
- `npm run docs:preview` — Preview the production build locally.
